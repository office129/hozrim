# סיכום מפגש אוטומטי — מדריך התקנה

הסקריפט הזה רץ ב-Google Apps Script (בחשבון Google שלך, זה שבו יושב הדרייב של הלקוחות),
לוקח את הקלטת המפגש מתוך תיקיית המפגש בדרייב, שולח אותה ל-Gemini, ומייצר **מצגת סיכום PDF**
בסגנון החם של "חוזרים לבראשית" — ושומר אותה *באותה תיקיית מפגש*.
האפליקציה כבר יודעת לקלוט לבד כל PDF שמופיע בתיקיית מפגש, אז משם זה מגיע ללקוח אוטומטית.

זה מחליף את השלב הידני של NotebookLM.

---

## מה צריך פעם אחת

### 1. מפתח Gemini API
1. היכנס ל-https://aistudio.google.com/app/apikey (עם חשבון Google שלך).
2. לחץ **Create API key** והעתק את המפתח.

### 2. יצירת פרויקט Apps Script
1. היכנס ל-https://script.google.com → **New project**.
2. תן שם לפרויקט, למשל: `סיכום מפגשים - חוזרים לבראשית`.
3. מחק את התוכן של הקובץ `Code.gs` שנפתח, והדבק במקומו את כל התוכן של **`Code.gs`** מהתיקייה הזו.
4. בצד שמאל, ליד **Files**, לחץ על ⚙️ **Project Settings** → סמן ✔ **"Show `appsscript.json` manifest file"**.
5. חזור ל-**Editor**, פתח את `appsscript.json`, ומחק/הדבק במקומו את התוכן של **`appsscript.json`** מהתיקייה הזו.

### 3. הפעלת שירות Slides המתקדם (לכיווניות עברית טובה יותר)
1. ב-Editor, ליד **Services** (בצד שמאל) לחץ **+**.
2. בחר **Google Slides API** → **Add**.
   (אם לא מצליח — לא נורא, המצגת עדיין תיווצר; זה רק משפר יישור מימין לשמאל.)

### 4. מילוי ההגדרות בראש `Code.gs`
בתוך `var CONFIG = { ... }`:
- **`GEMINI_API_KEY`** — הדבק את המפתח מסעיף 1.
- **`ROOT_FOLDER_ID`** — פתח בדרייב את התיקייה `חוזרים לבראשית - לקוחות`,
  והעתק מהכתובת את המזהה שמופיע אחרי `/folders/`. הדבק אותו כאן.
  (אם תשאיר ריק, הסקריפט ינסה למצוא לפי השם — אבל עם ID זה הכי אמין.)

השאר אפשר להשאיר כמו שהוא בשלב הזה.

## הרצת הבדיקה הראשונה (מפגש אחד בלבד)

חשוב: בהגדרות ברירת המחדל, כל הרצה מייצרת **מצגת אחת בלבד** (`MAX_MEETINGS_PER_RUN: 1`).
כדי לבדוק על מפגש ספציפי שאתה בוחר:

1. פתח בדרייב את תיקיית המפגש שרוצים לבדוק (זו שבתוכה יש את קובץ ההקלטה `mp4`/`m4a`).
2. העתק מהכתובת את ה-ID (אחרי `/folders/`).
3. הדבק אותו ב-`CONFIG.TEST_MEETING_FOLDER_ID`.
4. ב-Editor, בחר למעלה את הפונקציה **`generateMeetingSummaries`** ולחץ **Run** (▶).
5. בפעם הראשונה תתבקש לאשר הרשאות — אשר (Drive + חיבור לאינטרנט). ייתכן מסך
   "Google hasn't verified this app" → **Advanced** → **Go to ... (unsafe)** → **Allow**.
   זה בסדר — זה הפרויקט שלך עצמך.
6. עקוב אחרי הפלט ב-**Execution log** (למטה). כשהריצה מסתיימת — פתח את תיקיית המפגש
   בדרייב, ותראה קובץ בשם `סיכום מפגש - <שם הלקוח> - <תאריך>.pdf`.

> טיפ: אפשר קודם להריץ את הפונקציה **`dryRunListMeetings`** — היא רק *מדפיסה* אילו
> מפגשים והקלטות זוהו, בלי ליצור כלום. טוב לוודא שהמבנה מזוהה נכון.

**שלח לי את ה-PDF שנוצר (או צילום מסך שלו) לפני שממשיכים** — ככה נוודא שהסגנון והתוכן
מדויקים, ורק אז נפעיל על כל הלקוחות.

## מעבר לאוטומטי (אחרי שאתה מרוצה מהתוצאה)

1. נקה את `CONFIG.TEST_MEETING_FOLDER_ID` (השאר ריק `''`) — כדי שיסרוק את כל הלקוחות.
2. אם רוצים לטפל בכמה מפגשים בהרצה, העלה את `MAX_MEETINGS_PER_RUN` (למשל `20`).
   *(מפגש שכבר יש בו קובץ עם המילה "סיכום" — מדולג אוטומטית, אז אין כפילויות.)*
3. הוספת טריגר מתוזמן:
   - ב-Editor, בצד שמאל, לחץ על ⏰ **Triggers** → **Add Trigger**.
   - Function: `generateMeetingSummaries`
   - Event source: **Time-driven** → למשל **Hour timer** כל שעה, או **Day timer** לשעה קבועה.
   - **Save**.

מעכשיו, כל מפגש חדש שנכנס לתיקייה שלו יקבל סיכום PDF אוטומטי, בלי מגע יד.

## שאלות נפוצות / תקלות

- **"הגעתי למגבלת 1 מפגשים"** בלוג — זה תקין, זו הגבלת הבטיחות. העלה את
  `MAX_MEETINGS_PER_RUN` כשתהיה מוכן.
- **"אין קובץ הקלטה בתיקייה"** — ודא שההקלטה (mp4/m4a) באמת יושבת *בתוך* תיקיית
  המפגש. הסקריפט לוקח את הקובץ הגדול ביותר מסוג אודיו/וידאו.
- **הקובץ גדול מאוד** — הסקריפט מעלה ל-Gemini במקטעים של 8MB (לא טוען הכול לזיכרון),
  אז גם הקלטות של שעה+ אמורות לעבוד. אם בכל זאת נכשל על קובץ ענק — כתוב לי ונטפל.
- **הסיכום קצר/כללי מדי** — אפשר לעבור ל-`GEMINI_MODEL: 'gemini-2.5-pro'` (איכות
  גבוהה יותר, איטי/יקר יותר).
- **טעות בסגנון/תוכן** — שלח לי את ה-PDF ואת ה-Execution log ואני אכוונן את ההנחיה
  ל-Gemini (הטקסט נמצא בפונקציה `requestSummaryFromGemini_`).
